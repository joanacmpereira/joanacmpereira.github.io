# Joana Pereira — Médica Psiquiatra

Personal website for Joana Pereira, built as a responsive static page for GitHub Pages.

The site introduces Joana's clinical profile, consultation formats, training, research, and book. Appointment links use the existing Calendly page. The portrait is served from `assets/images/bio-photo.jpg`.

## Local preview

Open `index.html` in a browser. For the portrait to load, keep the repository's existing `assets/images/` directory beside the site files.
